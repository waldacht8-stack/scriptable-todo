# セットアップ手順（iPhone）

所要時間は約10分。一度設定すれば、以後の手作業はありません。

## 0. プログラムの導入（GitHub から、最初の1回だけ手作業）
1. Safari で `https://raw.githubusercontent.com/waldacht8-stack/scriptable-todo/main/src/TODO%20Update.js` を開き、全文をコピー
2. Scriptable → 右上 **＋** → コピーした内容を貼り付け → 上部のタイトルを **TODO Update** に変更 → 完了
3. 一覧の **TODO Update** をタップ →「更新完了」と出れば、TODO / TODO Lite / TODO Diag が揃う

以後、プログラムが更新されたら **TODO Update をタップするだけ**（数秒）。TODO のデータは上書きされません。


## 1. 初回起動（カレンダー・通知の許可）
1. Scriptable を開き、一覧の **TODO** をタップ
   - 一覧に出ない場合は、数十秒待ってから画面を下に引っ張って更新
2. 「カレンダーへのアクセス」→ **許可**（「フルアクセス」を選ぶ）
3. 「通知の送信」→ **許可**
4. TODO 一覧の画面が開けば成功。右上の「閉じる」で閉じる

> 許可を出し損ねた場合：設定アプリ → Scriptable → カレンダー（フルアクセス）・通知（オン）

## 2. ホーム画面ウィジェット
1. ホーム画面の空いている所を長押し → 左上の **＋（編集）**
2. 「Scriptable」を検索 → **中サイズ**（小・大でも可）を選んで「ウィジェットを追加」
3. 追加されたウィジェットを長押し → **ウィジェットを編集**
   - Script：**TODO**
   - When Interacting：**Run Script**
4. 画面の外をタップして完了

## 3. ロック画面ウィジェット（任意）
1. ロック画面を長押し → **カスタマイズ** → ロック画面
2. 時計の下のウィジェット欄 → Scriptable の **長方形**（または円形）を追加
3. 追加したウィジェットをタップ → Script：**TODO**、When Interacting：**Run Script**

## 4. 毎朝の自動実行（保険）
ウィジェットの更新タイミングは iOS 任せなので、毎朝確実に1回同期させます。

1. **ショートカット** アプリ → 下の **オートメーション** → 右上 **＋**
2. **時刻** を選ぶ → 時刻 **6:50**、繰り返し **毎日**
3. **すぐに実行** を選び、「実行時に通知」は**オフ** → 次へ
4. 「新規の空のオートメーション」→ アクションを追加で **Scriptable** を検索 → **Run Script**
5. Script：**TODO**、Parameter（展開して表示）：**sync** と入力、**Run In App はオフ**
6. 右上の **完了**

## 5. 使い方
- **予定** は iOS カレンダーに登録するだけ。今日〜45日先（設定で変更可）の予定が自動で TODO になります
- **TODO の追加**：画面下の「TODOを追加」。次も設定できます
  - 「カレンダーにも予定として登録」：iOS カレンダーにも予定を作る
  - **繰り返し**：なし／毎日／平日／毎週／毎月。完了すると次の回が自動でできる
  - **重要**（星）：一覧とウィジェットの先頭に固定
- **完了**：丸をタップ。ウィジェット（中・大）は行をタップするだけで完了（「元に戻す」付き）
- **編集・削除**：TODO の文字部分をタップ
- **表示切替**：上部の［今日］［週］［月］。週・月は左右スワイプで前後へ
- **期限前の通知**：長押しすると［完了］［10分後に再通知］
- **設定**：上部右の歯車。朝・夜の通知時刻（オン・オフ）、期限前通知のタイミング、取り込み範囲、取り込むカレンダー
- カレンダー由来の TODO を削除すると、その予定は再取り込みされません

## 困ったとき
| 症状 | 対処 |
|---|---|
| ウィジェットに「同期できませんでした」 | アプリ（TODO）を一度開くと原因が上部に表示されます |
| 通知が来ない | 設定 → Scriptable → 通知 がオンか確認 |
| 祝日まで TODO になる | 設定（歯車）→「取り込むカレンダー」でチェックを外す |
