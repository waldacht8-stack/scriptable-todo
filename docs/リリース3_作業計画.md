## 共通の規則

- 自分の持ち主のファイルだけ変える。ほかのファイルを変えたいときは監督に頼む（`SettingsButton()` を自分の画面の右上に置くのは各担当がやる）
- 色は `@Environment(\.palette)` の値だけを使う（ハードコードしない）。375pt 幅で収まること
- 「予定」ではなく TODO 管理の言葉。日本語の表記を自然に
- CI は macos-15-intel（Xcode 26.3）。長い修飾子の連鎖は型付きの let に分ける。ビルドの `error:` 行はすべてログに出る
- 画面写真：workflow の `shot <ファイル> <起動引数…>` で撮る（白い写真は自動で撮り直し）。自分の画面の写真が必要なら監督に頼むか、自分の枝の workflow に `shot` の1行を足す（統合時に監督がまとめる）
- 個人情報（氏名・メール・予定の中身・アカウント情報）をコード・ログ・コミットに入れない。トークンや鍵は端末の Keychain にだけ保存する
- push は自分の枝だけ。main には push しない。報告は「緑のコミットと run ID・見た画面写真・変えたこと」
