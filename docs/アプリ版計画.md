# 正式アプリ版（TODO＋起床の統合）計画

2026-10-08

## 1. 目的
Scriptable で作った2つのアプリ（TODO・起床）を、1つの正式な iPhone アプリ（Swift／SwiftUI）にまとめる。

Scriptable の制約（Close ボタン、起動時の Scriptable 一覧、ウィジェット上で操作できない、デザインの反映が遅い、時計アプリのアラームをショートカット経由でしか操作できない）をなくす。

## 2. 前提・方式
| 項目 | 内容 |
| --- | --- |
| 費用 | 0円 |
| 開発 | Windows の VS Code で Swift を書く。Mac は使わない |
| ビルド | GitHub Actions の macOS 環境（公開リポジトリは無料）。XcodeGen でプロジェクトを作り xcodebuild |
| 確認 | iPhone シミュレーターで動かした画面のスクリーンショットを Actions が作る |
| インストール | ビルドした IPA を SideStore（無料 Apple ID）で入れる |
| 署名の更新 | 無料 Apple ID は7日で期限切れ。ショートカットのオートメーションで SideStore の「すべてのアプリを更新」を毎日実行して自動化 |
| 対象 | iOS 26 以上（AlarmKit を使うため） |

## 3. 統合アプリの構成
| 部分 | 内容 |
| --- | --- |
| アプリ本体 | タブで「TODO」「起床」を切り替え。設定とデザインは共通 |
| ウィジェット | 1つのアプリに複数のウィジェットを持たせる。追加するときの一覧に「TODO」「起床」が別々に並び、そこで選ぶ |
| データ共有 | アプリとウィジェットは App Group の共有フォルダで同じデータを読み書きする |
| ウィジェット上の操作 | TODO の完了、起床のチェックインを、アプリを開かずにウィジェット上のボタンで行う（iOS 17 以降の機能） |

## 4. 起床アプリの変わる点（見込み）
| 今（Scriptable） | アプリ版 |
| --- | --- |
| 時計アプリのアラーム「起床1〜4」をショートカットでオン・オフ | **AlarmKit でアプリ自身が段階アラームを鳴らす**（マナーモードでも鳴る）。ショートカット・時計アプリは不要に |
| チェックインはウィジェットのタップ → Scriptable が開く | アラームの画面のボタン、またはウィジェット上のボタンで完了 |
| 出発カウントダウンはウィジェットのタイマー表示 | ロック画面の「ライブアクティビティ」（常に最新の表示） |

## 4.5 アプリになることを活かした UI・機能
Scriptable 版をそのまま移すのではなく、iPhone の標準の操作感と OS の機能を使って作り直す。

### 操作（UI）
| 機能 | 内容 |
| --- | --- |
| スワイプ操作 | 行を右にスワイプで完了、左で削除・延期（明日へ） |
| 並べ替え | 長押しでドラッグして並べ替え。長押しメニューで重要・延期・カレンダー登録 |
| 触覚フィードバック | 完了・チェックインで軽い振動。お祝いは標準のアニメーションと紙吹雪 |
| すばやい追加 | 画面下の入力欄に「明日15時 歯医者」と打つと日時を読み取って登録（自然な日本語の日時入力） |
| アイコンの長押しメニュー | ホーム画面のアイコン長押しで「TODOを追加」「起きた！」 |
| デザイン | 4デザイン（クリーン・ナイト・ポップ・モノクロ）を SwiftUI で再現。ホーム画面アイコンのダーク・色付き表示にも対応 |

### OS の機能
| 機能 | 内容 | 用途 |
| --- | --- | --- |
| ウィジェット上の操作 | ボタンで完了・チェックイン（アプリを開かない） | TODO・起床 |
| ロック画面ウィジェット | 単色でも読める専用デザイン。タップで操作 | TODO・起床 |
| コントロールセンター | 「TODOを追加」「起きた！」のボタンを置ける | TODO・起床 |
| ライブアクティビティ／ダイナミックアイランド | 出発までのカウントダウンと今のルーティン、次のTODOの期限を、ロック画面と画面上部に常に表示 | 起床・TODO |
| AlarmKit | アプリ自身が段階アラームを鳴らす。アラーム画面の「起きた！」でチェックイン | 起床 |
| スタンバイ | 充電中に横置きすると、次の起床時刻・明日の予定を大きく表示（寝室の時計代わり） | 起床 |
| 通知のボタンをアプリを開かずに処理 | ［完了］［10分後に再通知］を押しても、アプリが前に出てこない | TODO |
| 共有シート | ほかのアプリの文章・URLを「TODOに追加」 | TODO |
| カレンダー（EventKit） | 取り込み・登録に加え、アプリ内で予定の時刻を直接変更 | TODO |
| バックグラウンド更新 | アプリを開かなくても、定期的にカレンダーを取り込み通知を予約し直す（毎朝のショートカットが不要に） | TODO |
| 設定の即時反映 | デザインを変えたらウィジェットもすぐ描き直す | 共通 |

### 無料の Apple ID で使えるか要確認
- App Group（データ共有）・AlarmKit・ライブアクティビティ・コントロールセンター・バックグラウンド更新
- ヘルスケアの睡眠データ（起床記録に使えると便利。無料では使えない可能性が高い）

## 5. 進め方
| 段階 | 内容 | 利用者の作業 |
| --- | --- | --- |
| 0. 検証 | 最小のアプリ＋ウィジェット2種類（TODO・起床）。App Group のデータ共有、ウィジェット上のボタン、AlarmKit、SideStore での自動更新を実機で確かめる | SideStore の導入（PC で1回）、アプリのインストール |
| 1. TODO 本体 | 今日・週・月、追加・編集、繰り返し、重要、設定、デザイン。スワイプ・並べ替え・長押しメニュー・すばやい追加・触覚 | 動作確認 |
| 2. TODO ウィジェット・通知・カレンダー | 期限が近い順、ウィジェット・ロック画面・コントロールセンターでの操作、アプリを開かない通知ボタン、バックグラウンド更新、カレンダー取り込み・登録、共有シート | 動作確認 |
| 3. 起床 | AlarmKit の段階アラーム、チェックイン、記録・スコア、ライブアクティビティの出発カウントダウンとルーティン、就寝リマインド、スタンバイ表示、起床ウィジェット | 動作確認 |
| 4. 移行 | Scriptable 版の TODO・起床のデータを取り込む | 1回だけ操作 |

移行が終わるまでは、Scriptable 版の2アプリをそのまま使い続ける。
