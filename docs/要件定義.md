# 要件定義 v0.2（確定）

## 前提・制約
| 項目 | 内容 |
|---|---|
| 利用者 | 本人のみ（iPhone 1台） |
| 費用 | 0円 |
| 基盤 | Scriptable（無料）＋ iOS ショートカット。開発は Windows、iCloud Drive 経由で配置 |
| 運用 | 手動作業なし（自動同期・自動通知、エラー時のみ通知） |
| データ | iCloud Drive `Scriptable/todo-data/todo-data.json`（保存のたびに `todo-data.backup.json` を作成） |
| デザイン | 案1：クリーン（ブルー × カード） https://claude.ai/artifact/MpeGZqzk6h3GkqBYXB4Vvk |

## 機能
### TODO
- 項目：タイトル、期限（日付のみ＝終日／日付＋時刻／なし）、メモ、完了、繰り返し（なし／毎日／平日／毎週／毎月）、重要（星）
- 繰り返し：完了すると次の回を自動作成（毎月は元の日を保ち月末は丸める、遅れて完了したら今日以降の回）。完了を取り消すと次の回も消える
- 重要：一覧の各区分・ウィジェットで先頭に固定
- お祝い表示：今日の分を全部終えたら画面に「今日は全部完了！」（紙吹雪）、ウィジェットにも表示
- 設定画面（歯車）：朝・夜の通知時刻とオン・オフ、期限前通知（なし／ちょうど／10〜120分前）、取り込み範囲（14〜90日）、取り込むカレンダー
- 一覧：期限切れ／今日（期限なし含む）／今後／今日完了した分（折りたたみ）
- 表示切替：［今日］［週］（月〜日を日付ごと、左右スワイプで前後の週へ。別の週を見ているときだけ「今週」ボタンで戻る）［月］（カレンダーに日ごとの未完了件数、日付タップでその日の一覧、左右スワイプで前後の月へ。別の月を見ているときだけ「今月」ボタンで戻る）
- 追加・編集・削除・完了・完了の取り消し
- 完了から30日たったTODOは自動削除

### カレンダー連携（TimeTree の代替）
- iOS カレンダーの「今日〜45日先」の予定を、予定そのものとして TODO 化
- 除外：日本の祝日・誕生日カレンダー
- 予定の変更・削除は未完了の TODO に自動反映。完了済みは変更しない
- カレンダー由来の TODO はタイトル・日時を編集不可（メモのみ可）。削除すると再取り込みしない
- 追加画面の「カレンダーにも予定として登録」で iOS カレンダーに予定を作成（時刻あり＝1時間、日付のみ＝終日、日時なし＝今日の終日。登録先カレンダーを選択可。結果は通知で知らせる）。作成後はカレンダー由来の TODO として扱い、同期で重複しない

### 通知
- 毎朝 7:00（設定で変更・オフ可）：今日の一覧（期限切れ件数＋先頭3件）。0件の日は送らない
- 期限の30分前（設定で変更・オフ可）：時刻指定のある TODO のみ。長押しで［完了］［10分後に再通知］
- 毎晩 20:00（設定で変更・オフ可）：今日の残り（期限切れ＋今日）。0件の日は送らない
- 自動処理の失敗：エラー通知（6時間に1回まで）

### ウィジェット
- 日・週・月の区切りなし。未完了TODOを「期限切れ → 期限が近い順 → 期限なし」で表示
- 色：期限切れ＝オレンジ、今日中＝青、それ以降・期限なし＝灰。各行に期限（14:00／明日 11:00／10/12（月）／期限なし）
- ホーム画面：小（未完了件数＋期限切れ件数 or 先頭1件）／中（未完了件数＋先頭3件）／大（先頭8件）
- ロック画面：円形（未完了件数）／長方形（一番期限が近いTODO）／1行
- 小・中・大に「次の期限まで h:mm:ss」（未来の時刻つきで一番近い期限まで。iOS が秒単位で更新。該当なしなら非表示）
- 中・大：各TODOの行をタップ → そのTODOを完了にしてアプリ画面を開く（「元に戻す」付きのお知らせを6秒表示）
- 小・ロック画面：タップでアプリ画面を開く（iOS の制約で行ごとのタップは不可）

### 自動実行のタイミング
- ウィジェット更新時（iOS 任せ、目安15分〜）
- 毎朝 6:50 のショートカット・オートメーション
- アプリを開いたとき

## 対象外
- 複数端末・他人との共有、TimeTree との直接連携、ウィジェット上での完了操作
