# 5ch の取り込み範囲の調査（2026-10-09）

情報タブの「話題」に 5ch のスレッドを入れられるかを調べた。結論：**スレッドの題名だけを取り込み、本文は公式の Web ページで開く形**なら、規約上の心配が小さく、作るのも軽い。返事をもらってから実装する。

## わかったこと

| 時期 | できごと | 出典 |
|---|---|---|
| 2015-02 | 専用ブラウザを作って公開するには、運営（Loki Technology）の許諾を得て公式 API を使う必要がある。**スクレイピングによる専用ブラウザの開発・公開は禁止** | developer.5ch.net（はてなブックマークの引用） |
| 2023-07-11 | API のキー（MonaKey など）が廃止され、**dat ファイルへの直接アクセスが再び解放**された。稼働中のスレッドは `/板名/dat/スレッドキー.dat`、過去ログは `/板名/oyster/…` | 5ちゃんねる wiki「Monazilla/develop」 |
| 2025 | ドメインが 5ch.net から **5ch.io** へ移った（板のサーバー名が変わる） | 5ちゃんねる wiki・各スレッドの URL |

- 板ごとの `subject.txt`（スレッドの一覧：スレッドキー・題名・レス数）と `dat`（本文）は、Shift_JIS・改行区切りの文字列
- User-Agent は `Monazilla/1.00 (アプリ名)` の形がならわし
- 2015 年の「許諾が必要」という規約は取り消されたと書かれた公式の文書は見つからなかった。dat の解放は事実上の黙認に近く、**公開リポジトリで本文まで読める専用ブラウザ相当を配るのは、規約の点で灰色**

## 取り込みの案

| 案 | 中身 | 規約の心配 | 手間 |
|---|---|---|---|
| **A（おすすめ）** | 選んだ板の `subject.txt` だけを読み、話題のキーワードに合うスレッドの**題名・勢い（レス数/時間）**をカードに出す。タップで公式の `read.cgi` ページを開く | 小さい（題名の一覧だけ。本文は公式ページで読む） | 小 |
| B | A に加えて、カードの裏に `dat` から最初の数レスを出す | 中（本文を自前で表示＝専用ブラウザに近づく） | 中 |
| C | スレッド全体をアプリ内で読む・書き込む | 大（専用ブラウザそのもの。書き込みは規約で不可） | 大 |

A のときの約束：取得は話題の更新と同じ間隔（30分より短くしない）、板は多くても5つ、書き込みはしない、本文は保存しない。

## 決定（10/9）

ユーザーの返事：「本文は Web ページをアプリ上で見られるように」→ **案 A で実装**。

- 話題の「集める先」に「5ch」を追加（InfoSource.fivech。初期値はオフ。話題ごとにオンにする）
- 題名の検索は ff5ch.syoboi.jp の RSS（`?q=<キーワード>&alt=rss`）。板を選ばなくても、全板の題名から探せる
- カードをタップすると、公式の read.cgi のページをアプリ内のブラウザ（SFSafariViewController）で開く。本文は取り込まない
