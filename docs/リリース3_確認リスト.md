# リリース3 確認リスト（QA）

QA 担当（r3/qa）がまとめる。テストで見つかった不具合・表記・見た目の気になる点を、持ち主ごとに並べる。
直すのは各担当（QA は製品のコードを変えない）。直したら「状態」を「済」にする。

## 1. 単体テスト

- 場所：`ios/Tests/*`（ターゲット `TodoAppTests`。アプリを入れ物にして `@testable import TodoApp`）
- CI：`.github/workflows/ios.yml` の「単体テスト（シミュレーター）」。シミュレーター用ビルドの後に `xcodebuild test -scheme TodoApp` を走らせる。失敗したテスト・既知の不具合・件数をログに出す
- 時刻：いま＝2026-10-09（金）10:00、時間帯は Asia/Tokyo に固定（`TEST_RUNNER_TZ` とテスト内の `NSTimeZone.default`）
- 見つかった不具合は `knownBug(...)`（`XCTExpectFailure`、strict ではない）で「既知の失敗」にしてある。直れば自然に通るので、直した担当は `knownBug` の囲みを外す
