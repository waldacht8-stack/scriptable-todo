## 2. 画面の作り方（デザインの統一）
- 色・書体・角の丸みは **`@Environment(\.palette) private var p` だけ** を使う（`ios/App/Theme.swift`）。色を直接書かない（警告の赤・星の黄色など意味のある色を除く）
  - 背景：`.paletteBackground(p)`、カード：`.paletteCard(p)` または `p.card`、本文 `p.text`、補足 `p.sub`、強調 `p.accent`、警告 `p.overdue`、強調の上の文字 `p.onAccent`、角丸 `p.radius`
  - 大きな数字の見出し：`BigCount(prefix:value:suffix:)`
- 構成の考え方は「フォーカス」に合わせる：大きな文字と余白、カード、全幅（`.frame(maxWidth: .infinity)` を忘れない。横幅のずれは利用者から指摘あり）
- 標準の部品（`List`・`Form`）を使うときは `.scrollContentBackground(.hidden)` ＋ `.paletteBackground(p)`、行は `.listRowBackground(p.card)`
- 文言はすべて日本語。日付は `JP.date(_:)`・`JP.time(_:)` など（端末の言語に関係なく日本語）
- 触覚：完了などの操作に `.sensoryFeedback(.success, trigger:)`

## 3. データ
- 保存は `SharedStore.load(_:from:)` / `SharedStore.save(_:to:)`（App Group の共有フォルダ。ウィジェットと共有）。ファイル名は担当ごとに接頭辞：`wake-*.json`、`habit-*.json`、`focus-*.json`
- 型は `Codable`。後から項目を足しても古いファイルを読めるよう、追加の項目は省略可能（`?`）にするか `decodeIfPresent` で読む
- 保存すると `WidgetCenter.shared.reloadAllTimelines()` が自動で呼ばれる
- **個人情報（氏名・住所・予定の中身など）をコードやテストデータに書かない**。見本データは一般的な内容にする

## 4. 通知・アラーム・ライブアクティビティ
- 通知の識別子は接頭辞で分ける：`wake-`、`habit-`、`focus-`（TODO は `todo-`）。予約を消すときは自分の接頭辞だけ消す
- アラームは AlarmKit（iOS 26。実機で鳴ることを確認済み）。`#if canImport(AlarmKit)` と `if #available(iOS 26.0, *)` で囲む
- ライブアクティビティは ActivityKit。`ActivityAttributes` は `ios/Shared/` に置く（アプリとウィジェットの両方で使うため）。表示は `ios/Widget/` の `ActivityConfiguration`
- ウィジェットのボタン操作は `AppIntent`（`ios/Shared/` に置く）

## 5. ビルドと確認（Mac なし）
- 手元では Swift をコンパイルできない。**GitHub Actions でビルドして確かめる**
- 自分の作業ブランチ（`feature/wake`、`feature/habit-focus`）に push すると `.github/workflows/ios.yml` が動く
  - 結果：`gh run list --branch <ブランチ> --limit 1`、失敗の原因：`gh run view <ID> --log-failed | grep -E "error:"`
  - gh：`"/c/Program Files/GitHub CLI/gh.exe"`、push：`git -c credential.helper= -c 'credential.helper=!"/c/Program Files/GitHub CLI/gh.exe" auth git-credential' push -u origin <ブランチ>`
- **push する前に、差分に個人情報が無いことを確認する**（公開リポジトリ）
- `main` には push しない（統合役がマージする）
- シミュレーターのスクリーンショット：起動引数 `-demo`（見本データ）、`-tab <番号>`、`-theme <focus|night|dawn|paper>`、`-layout <focus|board|thumb|timeline>`。自分のタブの撮影を workflow に足したいときは報告に書く

## 6. 前提・制約
- 無料の Apple ID ＋ SideStore で配布。追加できるのはこのアプリ1つと拡張1つ（ウィジェット）だけ。**新しいターゲット（拡張）を増やさない**
- 有料の機能（iCloud 同期、プッシュ通知など）は使えない
- 外部 API は無料・キー不要のもの（Open-Meteo）だけ
